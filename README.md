# لینگوپلاس: آموزش تعاملی زبان انگلیسی

## تغییرات این نسخه
- تنظیمات در منو (آیکون چرخ‌دنده): تم شب، اندازه‌ی متن، هدف روزانه و دیدن دوباره‌ی معرفی
- لوگوی جدید لینگوپلاس (ماسکات کتاب با هدفون): در هدر، منو، صفحه‌ی خانه، اسپلش و آیکون اپ
- صفحه‌ی اسپلش + دو اسلاید معرفی (فقط بار اول): تأکید روی اینکه برنامه برای کسانی است که اصلاً نمی‌توانند با زبان ارتباط بگیرند و همه‌چیز خیلی ساده است
- رفع باگ تمرین‌های درس: ارتفاع ثابت مودال (دیگر بزرگ و کوچک نمی‌شود)، قفل اسکرول صفحه‌ی پشت، شروع دوباره‌ی تمرین از اول در بار بعد
- باشگاه جمله‌سازی: تغییر گزینه‌ها با کشیدن مستقیم یا لمس فلش‌های بالا و پایین
- بخش جدید «پیش‌نیاز» (قدم صفر): جمله‌سازی، ضمیرها، اسم و صفت، حروف تعریف، کلمات پرسشی و دیگر قواعد پایه
- هدر شناور جدید (منوی سه‌خط، لوگو، نام برنامه، زنگ اعلان با شمارنده)
- منوی کناری که از سمت راست وارد می‌شود و با کشیدن به سمت بیرون بسته می‌شود
- نوبار پایین کپسولی + دکمه گرد «+» برای شروع سریع تمرین
- فونت کل برنامه: وزیر (Vazirmatn) به‌صورت آفلاین داخل برنامه
- صفحه ۱۲ زمان: خط زمان (گذشته ← الان → آینده) + نمودار شکل عمل هر زمان
- بخش «کجاها به کار می‌رود؟» با مثال برای هر ۱۲ زمان
- آیکون‌های مرتبط برای هر زمان (رنگ‌ها همان قبلی)
- حذف یادداشت‌های برنامه‌نویس مثل «از چپ به راست»
- رفع باگ‌ها: انیمیشن‌های تعریف‌نشده، آمار ساختگی کاربر جدید، زنجیره روزانه که هیچ‌وقت آپدیت نمی‌شد، شمارنده امروز که روز بعد صفر نمی‌شد، امتیاز تکراری با تکمیل دوباره درس، تاریخ UTC به‌جای تاریخ محلی، ثبت نشدن زمان‌های یادگرفته، ذخیره نشدن تنظیم صدا، دکمه برگشت اندروید، فونت وابسته به اینترنت

## اجرا در مرورگر
```bash
npm install
npm run dev
```

## ساخت APK (وب‌ویو با Capacitor)

### روش ۱: روی کامپیوتر خودت
پیش‌نیاز: Node.js 20+، JDK 21، Android Studio (Android SDK)
```bash
npm install
npx cap add android      # فقط بار اول
npm run apk              # build + sync + gradle
```
فایل APK اینجاست: `android/app/build/outputs/apk/debug/app-debug.apk`

یا با `npm run apk:open` پروژه را در Android Studio باز کن و از منوی Build > Build APK بساز.

آیکون و اسپلش اندروید از پوشه‌ی `assets/` ساخته می‌شود (بعد از `npx cap add android`):
```bash
npx @capacitor/assets generate --android
```

### روش ۲: بدون نصب هیچ چیز (GitHub Actions)
1. پروژه را در یک ریپوی GitHub آپلود کن.
2. تب Actions → Build Android APK → Run workflow
3. بعد از چند دقیقه، APK آزمایشی را از بخش Artifacts دانلود کن. برای بازار از workflow جداگانه‌ی Android Release استفاده کن؛ خروجی آن امضاشده است.

## انتشار نسخه‌ی Release در کافه‌بازار

نسخه‌ی بازار باید با کلید امضای خودت ساخته شود. کلید امضا را فقط یک بار بساز و برای تمام به‌روزرسانی‌های همین برنامه نگه دار؛ فایل کلید را در GitHub یا داخل ریپو بارگذاری نکن.

### ساخت کلید امضا در ویندوز

در PowerShell اجرا کن و برای کلید رمزهای مطمئن انتخاب کن:

```powershell
keytool -genkeypair -v -keystore lingoplus-release.jks -alias lingoplus -keyalg RSA -keysize 2048 -validity 10000
[Convert]::ToBase64String([IO.File]::ReadAllBytes("$PWD\lingoplus-release.jks")) | Set-Clipboard
```

در GitHub، از مسیر **Settings → Secrets and variables → Actions** این Secretها را اضافه کن:

| نام Secret | مقدار |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | محتوایی که در کلیپ‌بورد کپی شد |
| `ANDROID_KEYSTORE_PASSWORD` | رمز keystore |
| `ANDROID_KEY_ALIAS` | `lingoplus` |
| `ANDROID_KEY_PASSWORD` | رمز کلید |

### ساخت Release

پس از push کردن تغییرات، برچسب نسخه را بساز و push کن:

```bash
git tag v1.2.0
git push origin v1.2.0
```

فرایند **Android Release** یک APK و یک AAB امضاشده می‌سازد و آن‌ها را به GitHub Release نسخه‌ی `v1.2.0` پیوست می‌کند. برای بارگذاری در بازار، فایل `app-release.apk` را بردار. اجرای دستی فرایند از تب Actions هم فایل‌ها را به‌صورت Artifact می‌سازد.

برای نسخه‌های بعدی، `version` در `package.json`، `versionName` و `versionCode` در `android/app/build.gradle` را افزایش بده و همان کلید امضای قبلی را استفاده کن.
